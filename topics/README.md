## Senior-Level Answer Framework

For every theory question, structure your answer:
1. **Define** — one clear sentence
2. **Problem it solves** — the "why"
3. **How it works** — the mechanism
4. **Trade-offs** — when NOT to use it
5. **Real example** — anchor to your experience
